# Benison Jacob Benny — Portfolio

Single-page portfolio for an MSc Data Science student, built while applying to intern at Wispr Flow.

Static React app (CRA + Tailwind). No backend, no database, no login.

## Run locally

```bash
yarn install
yarn start
```

Set `REACT_APP_BACKEND_URL` in a `.env` file if your setup requires it (this site makes no API calls).

## Stack

- React 19, Tailwind CSS, Framer Motion, Lenis smooth scrolling
- Fonts: EB Garamond (headlines), Inter (body)
